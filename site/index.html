TinyLLM 最小範例（可操作，Lean 4 驗證）

一個最小的自迴歸 Transformer（一個字一個字往下預測），從查表到選出下一個字，每一步都有：1 層 attention、1 個 ReLU MLP、輸入輸出共用嵌入表、greedy 選字。比真正的模型少了 LayerNorm、位置編碼、多個 head 和多層，也沒有偏差項（bias）。156 個權重是用一句話「the cat sat on the mat .」訓練出來，再四捨五入到小數一位。改下面的數字或切換開關，每一步都會即時重算；最後一張卡在瀏覽器裡直接跑 Lean，檢查同一個模型。

  • 維度 d 4
  • MLP 寬度 8
  • 詞表 7
  • 層數 1
  • head 1
  • 位置編碼 無
  • 權重 156
next = argmax softmax( MLP( x + Attention(x) ) · Eᵀ )
上下文（最後一個字用來預測下一個字）
加一個字
1查表：每個字換成一個向量
xⱼ = E[第 j 個字]

模型不認識文字，只認識數字。嵌入表 E 的每一列是一個字的 4 個數字，第一步就是查表。這個模型沒有位置編碼：兩個 “the” 拿到的向量完全一樣，它要靠 attention 從前文分辨自己是哪一個。

2Query、Key、Value：X 乘上三個矩陣
Q = X·W_Q K = X·W_K V = X·W_V

Q（查詢）：我在找什麼。K（鍵）：我有什麼可以被找。V（值）：被找到時要給出的內容。三個都是同一個 X 乘上不同的矩陣，矩陣是訓練學出來的。

算式：最後一個字的 q 怎麼算
3分數 Q · Kᵀ，再套上 mask

算式：最後一列的分數怎麼算
4Softmax：每一列加起來 = 1
wᵢⱼ = e^(Sᵢⱼ − max) / Σₖ e^(Sᵢₖ − max)

每一條代表一個位置「把注意力分給誰」。顏色是被注意的那個字。

算式：最後一列的 softmax 怎麼算
5用權重加權 V，再乘 W_O、加回 x
mixᵢ = Σⱼ wᵢⱼ·Vⱼ hᵢ = xᵢ + mixᵢ·W_O
V（原本的內容）mix（混合後）

V 是 4 維，這裡選兩個維度畫出來。mix 一定落在 V 點圍成的範圍內，因為它就是 V 的加權平均（投影到任兩個維度也一樣）。最後的 W_O 和殘差「加回 x」讓 attention 只需要學要修改多少，原本的資訊不會被蓋掉。

6MLP：展開、ReLU、壓回去
u = ReLU(h·W₁) m = h + u·W₂

算式：每一個乘法
7Logits → 機率 → 選字
logitₜ = m·E[t] p = softmax(logits) next = argmax p

輸出層共用嵌入表 E（tied weights）：m 的方向越像哪個字的嵌入向量，那個字的分數就越高。這裡用 greedy，永遠選最高的。

算式：每個 logit 怎麼算
8下一個字怎麼選：logits → Temperature → Top-K → Top-P → 抽樣

用第 7 步同一組 logits，改成抽樣。

順序：logits ÷ T → softmax → 只留機率最高的 K 個 → 再從最高往下累加到 P 為止 → 剩下的重新正規化 → 抽樣。
• Temperature：T < 1 讓高分的字更突出（更保守），T > 1 讓分布更平（更有創意也更容易亂講），T → 0 幾乎等於每次都選最高分（greedy）。
• Top-K：只留前 K 名，固定數量。
• Top-P（nucleus）：留下累積機率剛好到 P 的最少字數，數量會隨分布改變。分布很集中時只留 1–2 個，很平時會留很多個。
這個模型只學過一句話，機率非常集中，T 拉到 2 以上才常抽到別的字。

i重點

    
    
      
  • 沒開 mask 時每個 token 都能看所有人，這是 BERT 那類 encoder 的做法（雙向）。開了 causal mask，token 只能看自己和前面的，這是自迴歸 Transformer 一個字一個字生成文字的方式。Token 0 只能看自己，所以它的 mix 就等於它自己的 V。
    • 
      
  • 關掉 mask 時，最後一個字的預測不會變：它本來就看得到全部。改變的是前面的位置，它們開始偷看未來。Lean 的 no_peeking 定理證明的正是「後面加字不會改變前面的位置」。
    • 
      
  • √d 讓分數不會因為維度變大而太大，避免 softmax 變得太極端。模型是開著 √d 訓練的，關掉後預測可能改變。
    • 
      
  • Attention 決定「每個位置變成什麼向量」，Temperature／Top-K／Top-P 只在最後一步決定「下一個字怎麼選」，兩者互不影響。
    • 
      
  • 檔案開頭是 prelude 加上只 import Init.Data.OfScientific，所以瀏覽器只需要載入 一部分 Lean 核心函式庫，而不是全部。
